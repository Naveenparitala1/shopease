# ShopEase Requirements

## User stories
- US-1: As a visitor, I want to see all products so that I know what the shop sells.
- US-2: As a visitor, I want to register with name, email, and password so that I can buy products.
- US-3: As a customer, I want to log in and log out so that my cart and orders are mine.
- US-4: As a customer, I want to search products by name so that I find items quickly.
- US-5: As a customer, I want to browse by category and filter by price so that I see what fits my needs.
- US-6: As a customer, I want to sort products by price so that I can compare options.
- US-7: As a customer, I want to add, update, and remove cart items so that I control what I buy.
- US-8: As a customer, I want to pay by card or wallet so that I can complete my purchase.
- US-9: As a customer, I want to be stopped from buying more than the stock so that I never order unavailable items.
- US-10: As a customer, I want to see my order history so that I can track what I bought.
- US-11: As an admin, I want to add and update products so that the catalog stays current.
